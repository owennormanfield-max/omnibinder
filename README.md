# Omnibinder

Every Pokémon TCG printing in 14 languages, with collection tracking, 18 filters and photo search.

Data: [tcgdex/cards-database](https://github.com/tcgdex/cards-database) and [PokemonTCG/pokemon-tcg-data](https://github.com/PokemonTCG/pokemon-tcg-data). Card images and prices load live from TCGdex.
